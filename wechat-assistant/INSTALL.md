# 微信辅助器 · 一键版安装说明

> **拿到压缩包，只有两步：完整解压 → 双击「一键安装.bat」。**
> 不用装 Python、不用装依赖、不用配路径、不用填密钥、不用联网。

---

## 0. 具体怎么装

1. 把整个压缩包**完整解压**到一个固定文件夹（不放桌面临时目录、不放 U 盘）。
   - 路径带中文、带空格都没问题。
   - 别只解压出其中几个文件，`runtime/` 和 `bin/` 缺一不可。
2. 双击 **`一键安装.bat`**。它只做三件事：
   - 检查自带运行环境是否完整
   - 跑一次无界面自检（90+ 项）
   - 在桌面建「微信辅助器」快捷方式，然后自动启动
3. 看到「安装完成」就装好了。以后双击桌面图标即可。

> 首次启动会弹一次「一键接入」说明，勾选同意后按「同意并自动接入」。
> 详见下面第 2 节 —— **这是唯一需要你动手的一次**。

## 1. 包里有什么 / 没有什么

| 有 | 没有（已全部删除） |
|---|---|
| 自带 Python 3.13 运行环境（不用你装） | 任何聊天记录、会话内容 |
| 自带全部依赖（PySide6 / 解密组件） | 任何真实客户姓名、备注名、手机号、wxid |
| 微信 4.x 本地数据库解密与导出 | 任何预先存好的密钥 |
| 5 个页签：常用语 / 常用文件 / 客户名单 / 打标签 / 话术库 | 任何成交名单、退费名单、渠道 / 同事名单 |
| 成交话术归因引擎、客户打分词典 | 任何公司名、官网、账号、报价、成功率数字 |
| 成交客户识别：昵称 / 备注 / 标签 + 自定义词典 + 自动学词 | 任何预先写死的成交 / 退费客户名单 |
| 密钥捕获组件 `bin/wx_key.dll` | 任何本机绝对路径、运行日志、截图、报告 |

**包里没有任何客户数据。** 所有名单、报告、话术都是装好之后，从**使用者自己电脑**上的微信里现算出来的。

## 2. 首次启动：唯一需要动手的一次

启动后程序会自动跑完整条流水线：

```
定位微信 → 取本机数据库密钥 → 解密聊天记录 → 出今日跟进 / 潜在意向名单
        → 成交话术归因 → 生成报告和可复用话术库 → 自动填进软件
```

**如果这台电脑之前导出过微信记录**（有现成密钥），上面全部静默完成，一次都不用点。

**如果没有密钥**，会弹一次「一键接入」窗口。这是因为：

> 微信 4.x 的数据库密钥**只在登录那一瞬间产生**，运行中的微信进程内存里不留明文。
> 所以要拿到密钥，必须重启一次微信，让它在你手机确认登录时把密钥交给本地监听。
> 这是微信自身的安全机制，任何工具都绕不过。

点「同意并自动接入」后，程序自动关闭微信 → 挂监听 → 重新拉起微信，
**你只需在手机上点一下微信自己的「确认登录」**，后面全自动。
密钥会缓存在本机（`%LOCALAPPDATA%\微信辅助器\key.txt`），
以后点「一键更新」或每次开机都**不用再操作**。

> 不想接入就直接点「暂不接入」：常用语、常用文件、打标签三个页签照常能用，
> 客户名单页也可以手动「选文件」读入已有的聊天记录文件。

## 3. 五个页签怎么用

| 页签 | 怎么用 |
|---|---|
| **常用语** | 点卡片 → 文字进微信输入框 → **你点【发送】** |
| **常用文件** | 点卡片 → 文件进微信输入框 → **你点【发送】** |
| **客户名单** | 自动出「今日跟进 TOP / 潜在意向客户」→ 勾人 → **送去打标签** |
| **打标签** | 微信里打开「通讯录管理 → 标签 → 添加成员」→ 选名单 → 开始；最后【完成】自己点 |
| **话术库** | 看成交归因摘要、打开报告、把高转化话术**一键存进常用语** |

右上角 **「一键更新」**：随时重新解密最新聊天记录、重出名单和归因报告。

- 常用语 / 文件默认**只进输入框不发送**，发送永远留给你。
- 「吸附」把窗口贴到微信聊天界面右侧，跟着微信移动，高度与微信窗口上下对齐
  （不会比微信矮一截）。**切到其它应用会自动收起，不再挡住别的软件**，切回微信自动出现；
  微信最小化也一起收起。想让它一直挂着，点一下「已吸附」取消吸附即可。
- 点 × 是缩到托盘，**托盘右键「退出」**才是真退出。

## 4. 成交客户识别：按你自己微信里的写法调

**默认就会认**这些常见写法，不用配置：

| 位置 | 例子 |
|---|---|
| 微信备注名 | `张三 已成交`、`李四-付`、`【全款】王五`、`付25级新生` |
| 客户昵称 / 微信号 | `钱七 已付款`、`孙八 签单` |
| 微信标签 | `已成交`、`付款`、`付清`、`全款`、`签单`、`正式学员` |
| 聊天里的签约证据 | 甲方信息表、e签宝、对公账户、定金到账 |

同时**否定优先**：`未成交 / 没付款 / 待付 / 退费 / 放弃 / 高意向 / 潜在 / 同行`
不会被拆成「成交 / 付款」误判；`付老师`、`付小明同学` 这类姓氏也不会被当成
付了钱（单字「付」只在「看起来像标注」的位置才生效）。

判定分四档：`已确认成交` / `较大概率成交` / `疑似待确认` / `未成交`。
只有前两档会从「今日跟进」名单里剔除、进入成交归因；`疑似`只进核对清单，
默认**不算成交**，避免把还在谈的人误排掉。

### 每个人写法不一样，三种办法

1. **界面里勾（推荐，不用手打）**：设置 →「成交客户识别设置…」。
   程序会自动列出**本机微信里所有标签名**，以及从备注名里反复出现的
   「已结营 / 已经付费 / 已报价」这类标识，勾上就生效。
2. **界面里手写**：同一个窗口里，「我自己的成交标识」「看到就不算成交」
   两个框，一行一个词，写你自己的黑话即可。
3. **改配置文件**（高级）：`data/deal_signals.json`
   - `name_include` / `label_include`：追加成交标识
   - `negative_include`：追加否定词
   - `manual_deal` / `manual_not_deal`：按 wxid 或备注名强制指定
   - `disabled`：关掉某个内置词
   - `accept_suspect`：把「疑似」也算成交

改完点「保存并重新分析」，或点右上角「一键更新」重跑。

> **关于微信标签，有一件事要说清楚**：微信 4.x 的本地数据库只保存
> 「标签名清单」，**不保存「哪个联系人挂了哪个标签」**（关联在服务端）。
> 所以标签识别走两条路：
> ① 把标签名当标识词（勾一下就生效，覆盖「标签名写进备注」的常见做法）；
> ② 如果你有带标签的通讯录导出，做成 JSON 数组
> `[{"username":"wxid_xxx","labels":["已成交"]}, ...]`，
> 路径填到 `data/radar_config.json` 的 `contacts_file`，即可按 wxid 精确判定。

### 核对每一个判定

`输出/成交客户核对清单.csv` 逐人列出：备注名、昵称、判定档位、置信度、
**命中了哪个词、来自备注还是标签**、有没有排除词。界面「话术库」页点【核对】
即可打开。改判方式：在设置里加词，或填 `manual_deal` / `manual_not_deal`。
`输出/成交标识建议.csv` 是系统学到的新词候选，可以批量看。

## 5. 输出在哪里

点过「一键更新」后，`输出/` 目录会自动出现：

| 文件 | 内容 |
|---|---|
| `今日跟进名单.csv` | 只列未成交、今天该跟的客户，含阶段 / 静默天数 / 建议动作 |
| `潜在意向名单.csv` | 命中成交信号、未成交、未放弃的客户 |
| `成交话术归因报告_日期.md` | 成交链证据覆盖、异议→应答、复用话术 TOP、阶段流失 |
| `成交话术库_日期.csv` | 从成交会话里挖出的原话，可直接复用 |
| `归因摘要_日期.json` | 机器可读的统计摘要 |
| `成交客户核对清单.csv` | 每个成交/疑似判定的依据、置信度、命中词、是否可改判 |
| `成交标识建议.csv` | 从本机备注名与标签里学到的新标识候选 |

`data/打标签名单/` 里也会自动放好两份 `.txt`，可直接送去打标签。

> 这些文件**含聊天内容，只在这台电脑上**，请自行妥善保管，不要复制外传。

## 6. 隐私与边界（写死在代码里，没有开关）

- **只处理本机当前登录的微信账号**，不碰他人账号。
- **数据不出本机**：密钥、聊天记录、名单、报告全部只写本地文件，
  程序不联网、不上传、不含任何统计或遥测。
- **只读微信数据**，不修改微信任何文件；不后台驻留、不开机自启。
- **关闭 / 重启微信前必须显式同意**，绝不静默重启。
- 解密出的图片 / 语音 / 视频只保留类型标签，不还原媒体内容。
- 导出内容含客户隐私，使用前请自行确认已取得相关方同意，
  并遵守所在地法律法规与微信平台规则。
- 常用语 / 常用文件默认只进输入框，不自动发送。

**组件来源致谢**：`bin/wx_key.dll` 取自开源项目 WXexport-tool（v1.2.0，
作者 Ray0612，github.com/Ray0612/WeChat-Export-Tool），仅随本包在本机使用，
密钥只写入本机文件，不上传、不外传。感谢原作者的开放分享。

## 7. 常见坑

| 现象 | 原因 / 处理 |
|---|---|
| 双击没反应 | 先用「调试启动.bat」跑一次，错误会留在窗口；或看 `输出/启动错误.log` |
| 提示「缺少 runtime 文件夹」 | 压缩包没解压完整，重新完整解压 |
| 杀毒软件报毒 / 拦住 | 密钥捕获组件会挂载监听，部分安全软件会误报。加入白名单后用管理员身份跑一次；不接入也能用其它功能 |
| 「等待登录确认超时」 | 微信登录确认早于监听就绪。关掉微信，再点一次「一键更新」重来，别反复扫码 |
| 「密钥拿到了但解不开库」 | 换了微信账号，或数据目录不对。确认微信已登录完成 |
| 「没找到微信数据目录」 | 电脑版微信从未登录过，或聊天记录没存本机。先登录一次微信 |
| 名单里冒出已成交老客户 | 设置 →「成交客户识别设置…」把对方用的标识词勾上 / 写上；也可在 `data/deal_signals.json` 的 `manual_deal` 里强制指定 |
| 有人明明没成交却被判成交 | 打开「成交客户核对清单.csv」看命中词，把误伤的词加进 `negative_include` 或 `disabled` |
| 我用的是很特别的成交标记 | 在设置里手写一行；系统也会把本机标签名和高频备注片段列进「标识建议」 |
| 数字框黑边 / 不显示数字 | 别改 `ui/simple.qss` 里 `QSpinBox` 的按钮尺寸，会压扁输入区 |
| `Ctrl+V` 没反应 | 微信以管理员运行时，请用管理员身份启动辅助器 |
| 打标签换标签后没重跑 | 勾「清空进度重跑」；`F12` 可急停 |
| 托盘里是旧界面 | 托盘右键「退出」旧实例，再重新启动 |

改完跑一次 `runtime\python.exe app.py --selftest` 确认没改坏。
