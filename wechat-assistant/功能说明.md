# 微信辅助器 · 一键版

给客服 / 销售用的桌面小工具。**自带运行环境，解压双击就能用**；
装好自动读本机微信聊天记录，出跟进名单、潜在意向名单、成交话术归因报告。

> 第一次拿到请先按 [INSTALL.md](INSTALL.md) 走一遍（其实只有：解压 → 双击「一键安装.bat」）。
> **包里不含任何聊天记录、客户名单、密钥或账号信息**，所有数据都是装好后在自己电脑上现算的。

---

## 一、五个页签，每个只做一件事

| 页签 | 点一下发生什么 |
|---|---|
| **常用语** | 文字自动进微信输入框 → **你点【发送】** |
| **常用文件** | 文件自动进微信输入框 → **你点【发送】** |
| **客户名单** | 自动出「今日跟进 TOP / 潜在意向客户」→ 勾人 → 送去打标签 |
| **打标签** | 自动勾选名单里的人；最后【完成】你自己点 |
| **话术库** | 看成交归因结果，把打赢过的话术一键存进常用语 |

右上角 **「一键更新」** 是总开关：重新解密最新聊天记录 → 重出名单 → 重做归因。
程序每次启动也会自动跑一遍（本机已有密钥时完全无感）。

## 二、全自动流水线做了什么

```
① 自动定位微信主程序与数据目录（含自定义安装盘、多账号目录）
② 自动找密钥：本机已有 → HMAC 校验复用；没有 → 一次授权后登录时捕获并缓存
③ 解密 SQLCipher 4 本地库（message / contact / session），按会话归集成 jsonl
④ 客户名单：剔除群聊、公众号、机器人、内部同事、渠道同行、已成交 / 退费 / 放弃
⑤ 成交归因：按昵称/备注/标签识别成交单 → 对照未成交组 → 挖异议应答、复用话术、阶段流失
⑥ 落地：名单 txt + 两份 CSV + 核对清单 + Markdown 报告 + 话术库，自动填回软件
```

首次接入因为微信机制需要重启一次微信并在手机上点「确认登录」，之后全自动。
详见 INSTALL.md 第 2 节。

### 客户名单口径

- **今日跟进 TOP**：只列**未成交、今天该跟**的人。按「客户留言待回复 → 到点该主动触达
  → 有流失风险 / 高意向 / 临门一脚」排序；静默超过 14 天的沉睡客户自动降权。
  每行开头直接标「待回复 · 今天先回」「该触达 · 静默 6 天」。
- **潜在意向客户**：命中成交信号、未成交、未放弃，可调「意向分≥」控制松紧。
- 自动剔除：群聊、公众号、机器人、服务号、内部同事、渠道同行、已成交 / 已退费 / 明确放弃。
- 打分词典（价格 / 合同 / 名额 / 师资 / 风险 / 六阶段）集中在 `core/chat_radar.py` 顶部，可改。

### 成交话术归因

只看**真实发出过、且那单最后成了**的话术，不做主观臆测：

| 输出 | 说明 |
|---|---|
| 成交链证据覆盖 | 甲方信息表 / 合同 / 收款账户 / 定金，在成交组与未成交组的覆盖率与倍数差 |
| 异议 → 我的应答 | 只从成交会话里挖「客户提异议 → 我方怎么答」，按价格 / 拖延 / 对比 / 效果分四类 |
| 跨会话复用话术 TOP | 归一化聚类，统计在多少个成交单里用过，保留原句 |
| 阶段关卡流失 | 六步成交链每一步的触达数与后续成交率 |
| 成交周期 | 中位数、闪电单 / 长线单占比 |

报告里的每一句都是自己说过的话，可直接点「存入常用语」变成一键卡片。

### 成交客户是怎么认出来的

不看聊天记录猜，主要看**客户自己微信里的状态标注**：

- **备注名 / 昵称 / 微信号**：`张三 已成交`、`李四-付`、`【全款】王五`、
  `付25级新生`、`2026.5 签约 赵六`
- **微信标签**：`已成交`、`付款`、`付清`、`全款`、`签单`、`正式学员`
- **否定优先**：`未成交 / 待付款 / 退费 / 放弃 / 高意向` 不会被拆成
  「成交 / 付款」误判；`付老师`、`付小明同学` 这类姓氏也不会误伤
- **四档判定**：已确认 / 较大概率 / 疑似待确认 / 未成交。前两档才从今日跟进
  剔除并进归因；「疑似」只进核对清单，默认不算成交

每个人写法不同，所以：设置 →「成交客户识别设置…」会自动列出**本机微信的
全部标签名**和从备注里学到的高频标识（如 `已结营`、`已经付费`、`已报价`），
勾一下就生效；也能自己一行一个地写黑话。`输出/成交客户核对清单.csv` 逐人
列出命中了哪个词、来自备注还是标签、置信度多少，界面「话术库」页点【核对】打开。

> 微信 4.x 本地只存标签名、不存「谁挂了哪个标签」，所以标签走
> 「标签名当标识词 + 可选的标签文件」两条路；完整说明见 INSTALL.md 第 4 节。

## 三、其它细节

- **一键投送默认不自动发送**：只把内容放进输入框，发送动作永远留给你。
  设置里可改成自动回车。
- **吸附微信右侧**：25ms 跟随；拖动时只移动窗口、不重排界面；微信停稳约 0.2 秒后
  一次性对齐尺寸。**高度贴着微信窗口上下边缘**（外侧上下各留 6px；浮在微信内侧时
  顶部让开标题栏、底部让开输入框和【发送】键），不再用固定 720px 把窗口截短。
  宽度固定、内外侧切换有迟滞，缩放不横跳。
- **不挡别的应用**：吸附状态下，只有微信（或辅助器自己）在前台时才显示。
  切到浏览器、文档等其它应用约 0.4 秒后自动收起，切回微信自动出现且不抢键盘焦点；
  微信最小化 / 关闭也一起收起。自己从托盘双击呼出有 6 秒宽限，手动收起的窗口不会
  被自动弹回来。取消吸附后恢复普通置顶行为。
- **顶部栏收紧**：一行只放品牌和三个按钮，说明文字统一放状态条 / 底栏，
  长文字按窗口宽度自动省略，窄窗口下不再挤成一团。
- **打标签**：`F12` 急停，进度自动保存；换标签 / 换名单勾「清空进度重跑」。
  程序**只勾选，绝不点【完成】/【取消】**。
- **托盘**：点 × 缩到托盘，托盘右键「退出」才是真退出。
- **热键**：`Ctrl+Shift+Space` 显示/隐藏、`Ctrl+Shift+F` 搜常用语、
  `Ctrl+Shift+Enter` 送第一条常用语。
- **自检**：`runtime\python.exe app.py --selftest`（96 项）。

> 旧版完整界面（分类、变量、统计、插件）：`runtime\python.exe app.py --classic`。

## 四、隐私与边界

- **只处理本机当前登录的微信账号**，不碰他人账号。
- **数据不出本机**：不联网、不上传、无遥测。密钥、聊天记录、名单、报告全在本地。
- **只读微信数据**，不改微信文件；关闭 / 重启微信前必须显式同意；不后台驻留。
- 解密出的图片 / 语音 / 视频只保留类型标签，不还原媒体。
- 导出内容含客户隐私，请自行确认已取得相关方同意，遵守所在地法律法规与微信平台规则。
- 完整边界与组件来源致谢见 [INSTALL.md](INSTALL.md) 第 5 节。

## 五、技术说明

| 项 | 说明 |
|---|---|
| 运行环境 | 自带 Python 3.13.1 (embeddable) + PySide6 6.12 + pycryptodome + zstandard |
| 微信版本 | Windows 微信 4.x（3.x 数据结构不同，不支持） |
| 解密 | SQLCipher 4：PBKDF2-HMAC-SHA512 256000 轮，AES-256-CBC，页级 HMAC 校验 |
| 消息内容 | ZSTD 压缩自动识别解压；媒体类型只留标签 |
| 依赖 | 全部随包，安装不需要网络 |
| 数据格式 | `all_messages.jsonl`：`chat / chat_wxid / is_self / ts / type / content` |

`bin/wx_key.dll` 来自开源项目 WXexport-tool v1.2.0（Ray0612，CC 授权），
仅用于本机登录时捕获密钥，不联网下载、不上传任何内容。
